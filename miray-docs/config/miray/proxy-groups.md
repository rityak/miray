# `miray.proxy-groups`

```yaml
miray:
  proxy-groups:
    relative-tolerance: 10
```

## relative-tolerance

Допуск `url-test` в процентах от задержки самого быстрого узла. По умолчанию `10`. Действует на все группы `url-test`.

Группа остаётся на текущем узле, пока он не медленнее самого быстрого больше чем на большее из двух: [`tolerance`](../proxy-groups/url-test.md#tolerance) группы (миллисекунды) или `relative-tolerance` процентов задержки самого быстрого. Так допуск растёт вместе с задержкой: для узлов около 30 мс разница 5 мс — шум проверки, для узлов около 300 мс шум измеряется десятками миллисекунд, и фиксированный `tolerance` под одни узлы не подходит другим.

Пример: текущий узел — 100 мс, `tolerance` не задан, `relative-tolerance: 10`. Появился узел 95 мс — группа остаётся (100 не больше 95 + 9,5); появился узел 85 мс — переходит (100 больше 85 + 8,5).

`0` — как в mihomo: только `tolerance`.

Решение по-прежнему принимается по последней проверке каждого узла. Отказ узла этой опцией не задерживается: соединение уходит на следующий узел сразу (см. [переключение при отказе узла](../proxy-groups/index.md#переключение-при-отказе-узла)).
