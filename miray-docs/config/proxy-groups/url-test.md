# url-test

Выбирает живой узел с наименьшей задержкой последней проверки здоровья.

```yaml
proxy-groups:
  - name: auto
    type: url-test
    proxies: [node-a, node-b, node-c]
    url: https://www.gstatic.com/generate_204
    interval: 300
    tolerance: 50
```

Остальные поля — [общие](index.md).

> **miray:** если выбранный узел не подключился вовремя или вернул ошибку, соединение уходит на следующий по скорости узел, не дожидаясь таймаута; отказавший узел откладывается до проверки здоровья. Самый быстрый узел и `tolerance` при этом не меняются. Подробно — [переключение при отказе узла](index.md#переключение-при-отказе-узла).

## tolerance

Допуск, миллисекунды. Группа остаётся на текущем узле, пока он не медленнее самого быстрого больше чем на `tolerance`: без него группа переключалась бы на каждой проверке из-за колебаний задержки. По умолчанию 0.
