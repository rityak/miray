# Как устроена документация miray

Документация конфигурации ядра miray для пользователей. Разделы и пути — как у вики mihomo ([wiki.metacubex.one](https://wiki.metacubex.one/ru/), исходники — `MetaCubeX/Meta-Docs`), чтобы страницу было легко сопоставить с оригиналом. Формат — Markdown с front matter: собирается генератором вроде 11ty без правок.

## Что сюда попадает

- **Тронутый блок конфигурации** — полная страница блока: все параметры, как они работают в miray, и отметки, где поведение отличается от mihomo. Текст пишется по коду miray (поля конфига, умолчания), вики mihomo — образец структуры и порядка параметров. Текст вики не копируется: у `Meta-Docs` нет открытой лицензии.
- **Свои опции miray** — раздел [`miray`](config/miray/index.md) (блок `miray:` конфига, D-015).
- Нетронутые блоки — не переносятся; [карта отличий](differences.md) ведёт на страницу mihomo.

Блок считается тронутым, если в miray у него другое умолчание, другое поведение при тех же значениях или новые параметры. Изменения, которые не видны в конфиге и не меняют поведение (быстрее, меньше аллокаций), сюда не пишутся — они в `README.md` ядра.

## Структура

```
miray-docs/
  index.md              главная
  differences.md        карта отличий по блокам: страница miray или ссылка на mihomo
  config/
    miray/              блок miray: (только miray)
    inbound/tun.md      пути — как у вики mihomo (config/inbound/tun → config/inbound/tun.md)
    …
```

## Front matter

```yaml
---
title: TUN                      # заголовок страницы
description: …                  # одна строка для списка и поиска
lang: ru                        # одна локаль; перевод — рядом, page.en.md, как у mihomo
order: 10                       # порядок в разделе
section: inbound                # раздел вики mihomo (dns, inbound, proxies, proxy-groups, rules, …; miray — свой)
mihomo: https://wiki.metacubex.one/ru/config/inbound/tun/   # страница-оригинал; у страниц только miray нет
status: changed                 # changed — блок mihomo с отличиями; miray — есть только в miray
since: v1.19.33-miray.1         # с какой версии описано (D-014)
---
```

## Отметки отличий

Отличие от mihomo — цитата, начинающаяся с **miray**, сразу под параметром:

```markdown
## mtu

Размер MTU интерфейса.

> **miray:** по умолчанию на Linux 65535 (в mihomo — 9000), с откатом на 9000, если интерфейс не открылся. Явное значение не меняется.
```

Параметр, которого нет в mihomo, отмечается так же: `> **miray:** параметра нет в mihomo.` под заголовком.

## Как обновлять

- Слили в `dev` изменение, видимое в конфиге, — правится страница его блока (или создаётся, если блока ещё нет) и строка в [карте отличий](differences.md), в том же коммите или следом.
- Обновили upstream и у mihomo появился параметр в тронутом блоке — он дописывается и сюда.
